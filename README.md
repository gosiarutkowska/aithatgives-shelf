# The shelf — submissions for aithatgives.org

This is where apps are put forward for [aithatgives.org](https://aithatgives.org): apps made with AI
and simply given away.

## The rule

Every app on the shelf:

- **is FREE** — no price, no subscription, no “pro” version
- **has NO ADS** — nothing is sold, so nothing is sold to you
- **collects NO DATA** — no account, no tracking; it may download public data, it never uploads yours

And says openly that it was made with AI.

## How to submit

Open an issue with the **“Put an app on the shelf”** template and answer three questions:
what it does, who it's for, what it doesn't do. Any platform, any country, any language.
Closed source is fine.

## What happens next

Before an app goes on the shelf, I install it, read what permissions it asks for and what it sends
over the network, and publish what I found next to it. If I say no, I say why — in the issue.

No form, no account beyond GitHub. If you would rather not use GitHub, write to
hello@aithatgives.org.

## The mark

Any app that keeps the rule may carry the mark and the tag **#aiThatGives**. No permission needed,
no fee — the rule is the only licence. The mark is at <https://aithatgives.org/mark.svg>.
